# NOUSLAB

## [開啟網站 / Open Website](https://yeh0706.github.io/nouslab/)

中文說明如下；[English documentation](#english) is available below.

《崩壞：星穹鐵道》的計算工具網站：排軸、傷害、增益比較、回能與速度閾值，一個網頁全部搞定。

## 功能

| 分頁 | 用途 |
|---|---|
| 排軸工具 | 依隊伍速度、行動提前與拉條效果排出行動順序，含阿哈時刻 |
| 傷害計算 | 直傷、持續傷害、擊破、超擊破、擊破持續傷害、歡愉傷害、記錄型真實傷害，逐項列出各乘區 |
| 提升比較 | 填入 2–4 名角色的傷害占比，比較不同增益方案帶來的全隊總傷提升 |
| 回能計算 | 計算幾動能充滿終結技 |
| 速度閾值 | 已知開大時機，看第幾動需要多少速度 |

- 繁體／簡體中文介面切換，記住語言偏好
- 深色模式切換，預設跟隨系統
- 填過的數字存在自己的瀏覽器，下次打開還在
- 響應式版面，支援手機與桌面瀏覽器

## 使用方式

開啟上方網站即可使用，無須安裝或登入。上方分頁切換功能；手機上點右上角選單切換分頁。也可以下載後直接用瀏覽器打開 `index.html`。

## 檔案

```
index.html   網頁本體
calc.js      傷害計算核心
頭像/        角色、光錐、技能圖示
```

## English

### [Open Website](https://yeh0706.github.io/nouslab/)

A calculator toolkit for Honkai: Star Rail — turn order, damage, buff comparison, energy and speed breakpoints in one web page. The interface is in Chinese (Traditional / Simplified).

### Features

| Tab | Purpose |
|---|---|
| 排軸工具 Turn Order | Builds the action order from team speed, action advance and pull effects, including Aha Instants |
| 傷害計算 Damage | Direct, DoT, Break, Super Break, Break DoT, Elation and record-type True DMG, with every multiplier listed |
| 提升比較 Buff Comparison | Enter the damage share of 2–4 characters and compare how much each buff plan raises total team damage |
| 回能計算 Energy | How many actions it takes to fill the Ultimate |
| 速度閾值 Speed Breakpoints | Given when the Ultimate is used, the speed needed to reach each extra action |

- Traditional / Simplified Chinese switch with a saved preference
- Dark mode switch, following the system setting by default
- Inputs are saved in your own browser
- Responsive layout for desktop and mobile browsers

### Usage

Open the website above. No installation or login is required. Switch tools with the tabs at the top; on mobile, use the menu button at the top right. You can also download the files and open `index.html` directly in a browser.
